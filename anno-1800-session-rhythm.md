## HOW A SESSION WORKS

**Every session, same three beats:**

1. **OPEN (5 min)** — Read the Current Focus line. Glance at the balance and the storage bars. Fix anything that broke while you were gone *before* starting new work.
2. **WORK (~1h45)** — Pick **one** session type below. Do only that. Resist the urge to also fix the thing you noticed in the corner — write it in the Parking Lot instead.
3. **CLOSE (10 min)** — Run the Shutdown Check. Update Current Focus. Leave it clean.

**The one discipline that matters:** one job per session. The panic comes from doing five things at once. You have infinite sessions (no AI, no race) — so spend each on one thing done properly.

## SESSION TYPES (pick one per sitting)

### 🏗️ BUILD A TIER
*Grow one population level, properly.*
- Pick the tier you're upgrading. Open the calculator, get the building counts.
- Build every chain that tier needs — **including same-tier feeders** (windows before cannery). One chain at a time, each confirmed producing before the next.
- Upgrade houses **a few at a time**. If a need goes red while the new workers arrive, buy that good from a trader to cover the gap.
- **Done when:** the batch is stable, all needs green, balance recovered. Stop there — don't start the next batch tired.

### ⚙️ OPTIMISE ONE CHAIN
*Take one production line from "works" to "clean."*
- Pick one good. Open the production screen + calculator.
- Check the ratio (whole tons over a shared window). Cut starved surplus buildings. Oversize the raw end so it banks stock.
- If it's electrified: **delete the redundant half** and recheck.
- Set/adjust the trade route if it crosses regions — load-to-full, watch destination over cycles.
- **Done when:** the chain runs without you touching it, storage holding steady, nothing starving and nothing wasted.

### 🌳 BEAUTIFY
*Pure attractiveness + tourist income. The low-stress session.*
- Fill reserved green gaps: parks, ornaments, Botanica garden, zoo/museum/botanical sets.
- Check the attractiveness panel — watch the number and the tourist income climb.
- Slot cosmetic-pack ornaments freely here (this is where they belong).
- **Done when:** you've spent the beauty budget you wanted and the panel number is up. No wrong answers in this one — it's the session for a tired evening.

### 💰 FINANCE AUDIT
*Fix the bleed. Do this whenever balance feels tight.*
- Open the balance breakdown. Find the biggest upkeep drains.
- Switch **off** anything producing into a full warehouse (stockpile goods you're not currently spending).
- Check for starved/idle buildings paying upkeep for nothing.
- Confirm every populated island is net positive on its own, or is *deliberately* fed by another.
- **Done when:** per-tick balance is comfortably positive and you know *why* every big drain exists.

### 🚢 EXPAND A REGION
*Open or deepen a supply island. Heavier session — needs the full 2h.*
- New World / Enbesa / Arctic in the phase order. Mark out the monument and Hacienda spaces first.
- Stand up local construction materials before anything else.
- Set the supply route back to Crown Falls. Get it **visibly shipping** before you build the demand.
- **Done when:** the island supplies itself for building and one export is flowing.

### 🔬 SYSTEMS PASS
*Docklands, Research, Mail, Item Depot. The optimisation layer.*
- Pick **one** system. Set up or extend it.
- Docklands: concentrate one export good up the pyramid. Research: queue fertilities/nodes. Mail: one outpost route. Depot: link two islands.
- **Done when:** the system runs itself and you've noted its output in Current Focus.

### 🗺️ EXPEDITION / QUEST RUN
*The lighter, exploratory session.*
- Send a ship on an expedition, chase a timed quest, dive a wreck (Sunken Treasures).
- Camera/photo quest? Check the tech reminders — switch to GeForce Now if the pitch axis is locked.
- **Done when:** the expedition's away or the quest's done. Low commitment — good when you've only got half a session in you.

## SHUTDOWN CHECK (10 min, every session, no exceptions)

*This is the habit that lets the save survive gaps. Skip it and you reopen into confusion.*

- [ ] **Balance positive?** If not — Finance Audit is next session's job. Note it.
- [ ] **All needs green** on the tier you touched? Any red = note it in Current Focus so you don't forget.
- [ ] **Nothing half-built** left unpowered/unstaffed silently draining. Either finish it or note it.
- [ ] **Storage not pinned full** on anything you're actively producing (means a route or consumer is missing).
- [ ] **Update the Current Focus line** — phase, what you did, what's unfinished, what's next.
- [ ] **Parking Lot** — dump every "I noticed X" thought here so it's out of your head and off the map.

## THE POINT

You have unlimited sessions and no clock but your own. This save lasts because every sitting is **one job, done, left clean** — not the whole map juggled at once. The binge pace is what burned out the last saves; 2 focused hours that leave a readable game behind is what makes this the one that finishes.
